About Ocelin

A local companion for Codex and Claude. No account or API key needed. Native session return links are not assumed: open the project dashboard or its folder, then continue in the owning app.

App memory & CPU

Private RAM currently in use by recognized Codex, Claude and Ocelin processes, including their child tools. Desktop apps share processes across projects; these totals cannot be divided reliably between sessions.
